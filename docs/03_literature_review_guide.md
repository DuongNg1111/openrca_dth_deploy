# Literature review guide (M2) — for newcomers

Goal: understand the problem deeply and find our **novelty angle**. Output goes into `RESEARCH.md`.

## How to read a paper fast (3-pass method)
1. **Pass 1 (5 min):** title, abstract, figures, conclusion. Write 2 lines: problem + result.
2. **Pass 2 (30 min):** method + experiments. Write the "Method" and "Result" lines.
3. **Pass 3 (only if key):** re-implement the idea in your head; note assumptions/limits.
