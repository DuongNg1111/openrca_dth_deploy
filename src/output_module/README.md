# OUTPUT Module — Owner @thanhthanh278

## Job

The Output Module transforms the RCA results generated by the Process Module into standardized outputs for visualization and downstream applications.

Its responsibilities include:

- Aggregating evidence from multiple AI agents.
- Building the final Prediction object.
- Exporting results in the OpenRCA JSON format.
- Preparing dashboard-ready data.
- Supporting visualization in the Streamlit dashboard.

The Output Module focuses only on formatting and presenting RCA results. It does not perform reasoning or root cause inference.

---

## Contract

```python
build_output(candidates) -> Prediction

Prediction.to_openrca_json() -> dict

build_dashboard_data(prediction) -> dict

save_prediction(prediction, path)

render_report(prediction) -> str

plot_component_kpi(telemetry, component, kpi, out_path=None)
```

## Design Principle

The Output Module is independent of the visualization framework.

It prepares standardized outputs for downstream applications, while the Streamlit dashboard is responsible only for rendering the data.

This separation improves maintainability and allows the visualization framework to be replaced without modifying the Output Module.

## Beginner Steps

1. Verify that the generated Prediction follows the OpenRCA schema.
2. Aggregate reasoning results into a Prediction object.
3. Export Prediction to the OpenRCA JSON format.
4. Prepare dashboard-ready data.
5. Generate KPI visualizations.
6. Verify that the Streamlit dashboard correctly renders the generated outputs.
